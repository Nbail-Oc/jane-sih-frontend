# Project Jane - SIH 2026 Frontend

> SIH 2026 dark web de-anonymization and intelligence investigation frontend (Next.js)

---

## 🚀 Overview

Modern intelligence analyst dashboard and dark web de-anonymization investigation platform built for Smart India Hackathon (SIH 2026).

---

## 🛠️ Tech Stack

`Next.js 15` • `React 19` • `TypeScript` • `Tailwind CSS` • `Radix UI` • `Lucide Icons`

---

## ✨ Key Features

- **Dark web entity tracking, actor profiling, and correlation graphs**
- **Interactive investigation workspaces with digital forensics visualizations**
- **Seamless integration with Jane FastAPI intelligence backend**

## 📦 Getting Started

### Prerequisites

Ensure you have the appropriate runtime installed (Node.js 18+ or Python 3.10+ depending on project stack).

### Installation

```bash
# Clone the repository
git clone https://github.com/Nbail-Oc/jane-sih-frontend.git

# Navigate into the project directory
cd jane-sih-frontend
```

### Setup & Run

- If this is a **Node.js / Next.js** project:
  ```bash
  npm install  # or pnpm install / yarn
  npm run dev
  ```

- If this is a **Python / FastAPI** project:
  ```bash
  python -m venv venv
  source venv/bin/activate  # On Windows: .\venv\Scripts\activate
  pip install -r requirements.txt
  python main.py  # or uvicorn main:app --reload
  ```
